# Arabic-WSD-DGROM

## 1. Project Overview

This repository provides the implementation and experimental materials associated with the research paper:

**"Linguistic Mapping for Resolving Arabic Semantic Ambiguity Using the Discrete Golden Ratio Optimisation Method."**

The project investigates the application of the Discrete Golden Ratio Optimization Method (DGROM) to Arabic Word Sense Disambiguation (AWSD). The proposed approach aims to identify the appropriate meaning of ambiguous Arabic words according to their linguistic contexts.

The repository provides the DGROM implementation, corpus data, and experimental results used in the study.
